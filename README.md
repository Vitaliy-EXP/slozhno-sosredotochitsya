# Тематический сайт с переключением тем «Сложно сосредоточиться»

## Описание проекта
Сайт с адаптивной вёрсткой и поддержкой переключения цветовых тем. Проект выполнен по макету и использует принципы дизайн-системы, включая CSS-переменные и модульную архитектуру.

## Основной функционал

* Две темы: светлая и тёмная.
* Адаптивная вёрстка.
* Простая кастомизация за счёт CSS-переменных.
* Сложные декоративные элементы и эффекты.
* Семантическая разметка.

## Используемые технологии

* HTML5
* CSS3
* БЭМ
* CSS-переменные
* Media queries
* Flexbox / Grid

## Полученные навыки

* Создание дизайн-системы через переменные.
* Реализация темы интерфейса.
* Работа с адаптивной типографикой.

## Запуск проекта
Открыть `index.html.`
